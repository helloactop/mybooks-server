# 07 · Icons

## 1. 现状

Mybooks 没有图标字体、没有 sprite、没有统一图标组件。图标有三种来源：

1. 内联 SVG（绝大多数）；
2. Unicode 字形（✕、✎、⇄、◫、＋、⌕、⌄、☰、▦、☷ 等）；
3. 品牌位图（`logo-mark.png`、`logo.png`、公安备案图标）。

这是可用的，但不是统一的图标系统。本文件先登记实际尺寸/描边/用法，再给出新组件的规则。

Unicode 字形在不同系统/字体下形状和基线会变化。**新组件不得新增 Unicode 图标**；已有位置可以保留，但必须提供 `aria-label` 或可见文字。

## 5. 图标规范

### 5.1 尺寸

新组件使用：

| 角色 | 尺寸 | 描边 |
|---|---:|---:|
| 紧凑行内 | 14×14 | 1.4 |
| 默认 UI | 16×16 | 1.5 |
| 顶栏/主导航 | 18×18 | 1.8 |
| 大面积/播放 | 24×24 | 1.5–1.6 |
| 箭头/三角 | 10×6 或 8×5 | 1.2–1.3 |

现有 15px 只用于书架工具栏，属于既有视觉；新组件不要再用 15px。

### 5.2 结构

- 统一 `viewBox="0 0 24 24"`（小箭头除外）；
- `fill="none"` + `stroke="currentColor"` + `stroke-linecap="round"` + `stroke-linejoin="round"`；
- 纯方向/播放图标才允许实心 `fill`；
- 图标颜色继承文字色，不单独写十六进制；
- 图标与文字间距 6–9px；按钮内居中，不靠 margin 微调。

### 5.3 无障碍

- 纯装饰图标必须 `aria-hidden="true"`；
- 图标按钮必须有 `aria-label`，必要时加 `title`；
- 破坏性图标按钮（删除/移出/撤销）必须有可读的 `aria-label`，不能只有 `title`；
- 图标按钮的命中区不小于 44×44px（触屏）；桌面紧凑图标可以视觉 30–32px，但要有足够的内边距或真实 44px 命中区；
- 不依赖颜色区分图标状态；选中/展开同时用 `aria-pressed` / `aria-expanded`；
- 图标不能替代错误文案；错误要同时有文字。

## 7. 新组件图标规则

1. 优先复用已有 SVG path，不重新画近似图标；
2. 新增图标使用 24 viewBox、1.5 描边、currentColor；
3. 不在按钮里混用 Unicode 和 SVG 表达同一类操作；
4. 不在同一工具栏混用 1.2 和 1.8 描边表达同一层级；
5. 不新增 emoji；
6. 图标按钮必须有 hover、pressed、focus-visible、disabled 状态；
7. 图标与文案同时出现时，图标是装饰，文案是操作名称；
8. 纯图标操作必须有 tooltip 或 `aria-label`，但 tooltip 不能是唯一可访问名称。

## 8. 第二阶段建议

- 建立 `icon` 片段/函数，统一 24 viewBox 与描边；
- 把 `✕/✎/⇄/＋/⌕/⌄` 等高频字形替换为 SVG，但保留视觉尺寸与命中区；
- 统一顶栏、书架工具栏、行操作的描边为 1.5（顶栏可保留 1.8 的视觉重量）；
- 为 `.icon-btn`、`.wb-circle`、`.cat-op`、`.row-act` 建立同一套图标按钮尺寸；
- 增加“图标按钮只有 aria-label 是否可访问”的自动检查。
