# 12 · UI 视觉与交互验收标准

## 1. 适用范围

任何修改以下内容的提交：

- `public/css/*`；
- `public/js/chrome.js`、`overlay.js`、`book-details.js`、`common.js`、`modal.js`、`select.js`、`liquid-glass.js`、`shelf/*`；
- 页面 HTML 的结构/类名；
- 组件状态、动效、图标、间距、圆角、颜色；
- 影响首屏、滚动、焦点、草稿、异步顺序的行为。

不适用于纯文案、纯后端、纯数据修复，除非它们改变页面状态。

## 2. 验收前置

1. 记录基线提交 SHA；
2. 确认工作区干净（或明确哪些是本次改动）；
3. 使用临时存储/演示数据，不触碰真实书库（`MYBOOKS_STORAGE_DIR=<temp>`）；
4. 固定字体、缩放、DPR、浏览器版本；
5. 关闭或固定动画（截图时禁用 transition/animation，避免半帧）；
6. 同视口、同内容、同玻璃档位对比修改前后；
7. 截图不提交进仓库，放在临时目录或 CI artifact；报告只引用文字结论/路径说明。

### 3.2 状态矩阵

每个被改动组件至少检查：

- Default；
- Hover（桌面）；
- Pressed（鼠标/触摸）；
- Selected（如有）；
- Disabled（如有）；
- Loading（如有）；
- Error（如有）；
- Focus（键盘 Tab）；
- 减少动态；
- 减少透明度（涉及玻璃）；
- 玻璃 full / frost / solid（涉及玻璃）。

### 3.3 内容长度

- 短：1–4 字书名、无作者、无封面；
- 正常：10–30 字书名、单作者、有封面；
- 长：80–120 字书名、40+ 字作者、长简介；
- 空：0 本、0 标签、0 作者、0 结果；
- 大：分页边界（60 本）、facets 超限（作者/标签 80+）、表格多列；
- 特殊字符：中英混排、标点、emoji（仅内容，不作为图标）、超长无空格串。

## 4. 视觉验收标准

### 4.1 必须通过

- 页面结构、图书顺序、导航顺序、书架三栏/密度/断点与基线一致；
- 冷白画布、白色内容面、Action Blue、近黑文字不被新颜色替代；
- 选中态仍是中性亮玻璃，不出现黑/蓝实底；
- 书封、表格、正文没有玻璃/模糊/折射；
- 大面板（侧栏、Inspector、弹窗）仍是近实体，不是透明玻璃；
- 无横向滚动；无内容被裁切；无弹窗超出视口；
- 无 CLS：首屏、恢复侧栏、加载完成不推动网格；
- 字体不跳变；输入框在移动端不小于 16px；
- 图标按钮不出现只有图标、没有可访问名称的情况；
- 触摸目标不小于 44×44px（例外见下）；
- 修改前后差异只出现在声明的范围内。

### 4.2 允许的例外

- 桌面顶栏图标视觉 30×30（鼠标精确指针），但触屏必须 44–48px；
- `.btn-sm`/`.cat-op` 桌面 30–34px，触屏应有 44px（当前 `.cat-op` 未做到，属于债务）；
- 书架行桌面 36px，触屏 44px；
- 首页画廊的 1000ms/5000ms 动效；
- Apple 导航/搜索的 422ms/254ms/320ms 节奏；
- 书架 2:3 与展示 5:7 两种封面比例；
- 页面专属 hero（首页/榜单/统计/笔记/登录）不统一。

### 4.3 像素对比规则

- 静态 fixture/固定数据：允许 0 像素差异；字体/抗锯齿导致的 1px 边缘差异需人工确认；
- 数据驱动页面：只对比结构区域，动态文字/封面/计数用遮罩排除；
- 动画：截图前禁用 transition/animation，或固定在同一时间点；
- 玻璃：同档位对比（full↔full、frost↔frost、solid↔solid），不能拿 full 与 frost 直接 diff；
- 深色/浅色：当前只有浅色主题；不要凭空生成深色基线。

## 5. 交互验收标准

### 5.1 键盘

- Tab 顺序符合视觉顺序；
- 焦点可见（2px，offset 2）；
- 弹窗 Tab 循环，关闭后焦点归还触发源；
- 菜单/搜索/下拉 Escape 可关闭；
- 书架网格方向键/Home/End/Shift/Ctrl 行为不变；
- 表头 Enter/Space 排序，`aria-sort` 正确；
- 不使用鼠标也能完成：打开搜索、选择书籍、打开详情、编辑、保存/取消、切筛选。

### 5.2 触屏

- 点击不出现系统蓝框；
- 长按 500ms 进入多选，移动 >12px 取消；
- 无 hover 依赖：分类行操作、书架操作、详情操作在触屏可见；
- 抽屉可打开/关闭；遮罩可点；Escape 不适用时有可见关闭按钮；
- 滚动不穿透（搜索/菜单/弹窗/书架侧栏）；
- 输入聚焦不触发 iOS 自动放大。

### 5.3 受保护行为

- 书架滚动位置在返回/重渲染后保持；
- 侧栏展开/折叠状态保持；
- 分组折叠状态保持；
- 搜索输入焦点、光标、选中范围在 facet 重渲染后保持；
- 详情内联编辑草稿在重渲染后不丢失，焦点回到原输入；
- 异步请求结果不覆盖更新的输入/筛选（序列号保护）；
- 视图切换/密度切换后 `ensureFill()` 正确补足首屏；
- 删除/撤销/回收站路径不变。

### 5.4 玻璃

- full：真实折射，边缘弯折，中心清晰；
- frost：只有 blur/saturate/边缘，没有假折射；
- solid：无 blur/折射；
- 展开的菜单/搜索不透明；
- 弹窗遮罩不叠加 blur；
- 大面板不做折射；
- 折射面 ≤14（≤560px ≤10）；
- 减少透明度回退近实色；
- 减少动态关闭玻璃过渡。

## 6. 无障碍验收

- 图标按钮有 `aria-label`；
- 弹窗有 `role=dialog`、`aria-modal`，有可访问名称（`aria-label` 或 `aria-labelledby`）；
- 表单控件有 `<label>` 或 `aria-label`；
- 错误文案与字段关联（`aria-invalid`/`aria-describedby`）——当前缺失，新增组件必须做到；
- Toast 使用 `role=status` / `aria-live=polite`——当前缺失，新增反馈必须做到；
- 选中/展开/禁用状态有语义，不仅类名；
- 对比度：正文 ≥4.5:1；大字 ≥3:1；非文本 ≥3:1；
- 不使用颜色作为唯一信息；
- 减少动态/透明度可用；
- 200% 文字缩放不裁切主操作；
- 纯键盘可完成核心任务。

## 7. 测试与版本

1. 运行 `node scripts/test.js`（或 `npm test`），必须全绿；
2. 运行 `node scripts/check-public.mjs`（或 `npm run check:public`），必须通过；
3. `test/ui-unification.test.js` 必须通过；**禁止通过删除/放宽断言来掩盖回归**；
4. 若改了 `public/` 资源：
   - 更新所有 HTML 的 `?v=`；
   - 更新 `public/sw.js` 的 `SHELL_ASSETS`；
   - 递增 `CACHE_VERSION`；
   - 确认 `glass-lab.html` 不注册 SW；
5. 新增状态/组件时补测试：
   - token/结构断言；
   - 键盘/焦点/状态行为；
   - 异步顺序/草稿保护；
   - 重要页面状态；
6. 视觉变更必须有修改前后截图；截图不提交仓库。

## 9. 不通过的典型信号

- 为了让新样式成立，改了页面顺序/导航/书架布局；
- 书封或表格开始模糊；
- 侧栏/弹窗变成透明玻璃；
- 选中态变成蓝底/黑底；
- 手机出现横向滚动；
- 弹窗高度随地址栏跳变；
- 搜索关闭时误触“添加书籍”；
- 侧栏滚动位置回到顶部；
- 编辑草稿在重渲染后丢失；
- 旧异步结果覆盖新筛选；
- 测试被删/断言被放宽；
- 只提供“看起来更现代”而没有截图和参数证据。
