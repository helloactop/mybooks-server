## 2. 语义色与对比度

对比度按 WCAG 相对亮度计算，文本背景为白色 `#ffffff` 或画布 `#f5f5f7`。

| 组合 | 对比度 | AA 普通文本（4.5:1） | 结论 |
|---|---:|---|---|
| `#1d1d1f` on `#ffffff` | 16.83:1 | 通过 | 主文字 |
| `#6e6e73` on `#ffffff` | 5.07:1 | 通过 | 次文字 |
| `#86868b` on `#ffffff` | 3.62:1 | **不通过** | 仅可用于非关键/大字，现有 12px 用法是债务 |
| `#86868b` on `#f5f5f7` | 3.33:1 | **不通过** | 同上 |
| `#929399` on `#ffffff` | 3.06:1 | **不通过** | 书架三级文字，债务 |
| `#929399` on `#f7f8fa` | 2.88:1 | **不通过** | 书架侧栏，债务 |
| `#62646c` on `#f7f8fa` | 5.55:1 | 通过 | 书架分组标题 |
| `#35363b` on `#ffffff` | 12.05:1 | 通过 | 书架行 |
| `#0066cc` on `#ffffff` | 5.57:1 | 通过 | 链接/主操作文字 |
| `#0071e3` on `#ffffff` | 4.70:1 | 通过 | 焦点环（非文本 3:1 也通过） |
| `#c0392b` on `#ffffff` | 5.44:1 | 通过 | 危险操作 |
| `#e30000` on `#ffffff` | 4.92:1 | 通过 | 错误文案 |
| `#2f9e5f` on `#ffffff` | 3.40:1 | 非文本可接受 | 仅 6px 状态点，旁边有文字 |
| `#946200` on `#ffffff` | 5.24:1 | 通过 | 警告说明 |
| `#86868b` on `#1d1d1f` | 4.65:1 | 通过 | 深色背景次文字 |
| `#f5f5f7` on `#1d1d1f` | 15.46:1 | 通过 | 深色背景主文字 |

**结论：**当前最明确的对比度债务是 `--ink-3` / 书架 `#929399` 的小字号用法。它们已大量存在于日期、计数、提示、表头中；本阶段只登记，不在未获确认时统一加深颜色。

## 4. 强调色的使用边界

允许使用 Action Blue `#0066cc`：

- 链接文本（首页、详情、榜单、Markdown）；
- 主按钮文字与细边（`.btn-primary` 仍是中性玻璃，只把文字/边框染蓝）；
- 选中勾、排序/筛选的当前项；
- “在读”状态；
- 图表主色（年度柱状图、排行条）；
- 搜索结果的“保存当前 / 编辑”等文本操作。

不允许：

- 用蓝色实底表示选中（旧版黑/蓝实底已退役）；
- 用蓝色描边包住整个选中卡片；
- 用蓝色渐变/发光；
- 把蓝色用作大面积背景（首页深色区除外，链接使用 `#2997ff`）。

深色背景上的链接使用 `#2997ff`（`style.css:3728`），这是深色表面的可读性调整，不是第三个品牌色。

## 7. `theme-color` 契约

移动浏览器地址栏/状态栏颜色应与页面画布一致。当前基线不一致：

| 页面 | 当前值 | 规范值 | 结论 |
|---|---|---|---|
| 首页 | `#f5f5f7` | `#f5f5f7` | 正确 |
| 书架 | `#f6f5f2` | `#f5f5f7` | **旧暖白残留，需修** |
| 榜单 | `#ffffff` | `#f5f5f7` | 与画布不一致 |
| 统计 | `#ffffff` | `#f5f5f7` | 与画布不一致 |
| 分类管理 | `#ffffff` | `#f5f5f7` | 与画布不一致 |
| 心得 | `#ffffff` | `#f5f5f7` | 与画布不一致 |
| 登录 | 无 | `#f5f5f7` | 缺失 |
| Glass Lab | `#f5f5f7` | `#f5f5f7` | 正确（开发页） |

证据：`public/index.html:6`、`public/shelf.html:6`、`public/rank.html:6`、`public/stats.html:6`、`public/tags.html:6`、`public/notes.html:6`、`public/login.html:4`、`public/glass-lab.html:7`。

这条差异不影响页面主体，但会造成移动端浏览器栏与画布的颜色跳变，列入 P0 小修。

## 8. 颜色使用规则

1. 新组件不得写死十六进制颜色；使用 token 或页面局部 token。
2. 不允许新增蓝色实底选中；选中态继续使用中性玻璃。
3. 不允许新增红色；“危险操作”用 `--danger`，“错误反馈”沿用 `#e30000`，直到第二阶段统一。
4. 不允许把状态色用于装饰（例如给卡片加绿色/黄色边框）。
5. 深色表面上的文字必须重新检查对比度，不能直接复用浅色表面的 `--ink-*`。
6. 半透明玻璃上的文字必须保持深色 `--ink`/`--control-ink`，不能因为背景变亮而变浅。
7. 图表颜色只使用 Action Blue 家族，不引入彩虹色。
8. `theme-color` 必须与页面画布一致；本阶段只登记，不改代码。

## 9. 待确认事项

- 是否把 `#e30000` 统一为 `--danger`，或将 `--danger` 拆成 `--danger` 与 `--error` 两个语义 token；
- 是否加深 `--ink-3` / 书架 `#929399` 以满足 AA（会改变现有视觉，需要截图与用户确认）；
- 是否把 `#0071e3` 焦点色统一为 `--accent` `#0066cc`（会改变键盘焦点环颜色）；
- 是否把所有页面 `theme-color` 统一为 `#f5f5f7`。
