# 09 · Responsive

## 1. 断点地图

Mybooks 不是一个单一断点系统，而是四组：

| 组 | 断点 | 作用 | 证据 |
|---|---|---|---|
| 全局/管理 | `≤559.98` / `≥560` | 手机 vs 平板；普通网格 2→3 列；统计 hero 2→3 列；触屏详情尺寸 | `style.css:4490-4500`；`style.css:3086-3101` |
| 全局导航/书架 | `≤819` / `≥820` | 移动顶栏/菜单 vs 桌面导航；书架三栏 vs 抽屉 | `style.css:632-687,1311-1330,4502-4518`；`shelf-workbench.css:66,121,290,1232` |
| 书架专用 | `≤1180`、`≤560`、`561–819`、`≤370`、横屏 `max-height:560` + `≤1024` | Inspector 浮层/三栏、手机密度、排序隐藏、横屏抽屉 | `shelf-workbench.css:1195-1454` |
| Apple 展示 | `≤734`、`≤1068`、`≥1069`、`≥1441` | 首页画廊尺寸/排版 | `style.css:4382-4483` |
| 页面局部 | `≤480`、`≤640`、`≤834`、`≤720`、`≤500` 高、`≤390` | 榜单、Glass Lab、弹窗、详情 | `style.css:4728-4738,3563,3103-3107`；`glass-lab.html:136-147` |

### 1.1 断点成对规则

- 移动/桌面用 `max-width: 819px` 与 `min-width: 820px` 成对，中间不能有 819.5 的空隙；
- 手机/平板用 `max-width: 559.98px` 与 `min-width: 560px` 成对；
- 不要再新增 800–900 之间的断点；书架已有 1180，属于面板布局专用；
- 横屏手机用 `orientation: landscape and max-height: 560px`，不要只看宽度；
- 高度相关的弹窗规则使用 `max-height: 500px` / `560px`，并放在宽度规则之后以正确覆盖。

## 3. 安全区与视口单位

- 书架高度使用 `100dvh`；弹窗高度使用 `100svh`，避免地址栏显隐时弹窗跳高（`style.css:4511-4516`；`shelf-workbench.css:23`）；
- 底部浮动工具条、Toast、批量条都加 `env(safe-area-inset-bottom)`（`style.css:1850-1868`；`shelf-workbench.css:851,1169-1171`）；
- 手机弹窗左右/上下使用 `env(safe-area-inset-*)`（`style.css:4534-4543,4576-4587`）；
- 书架滚动容器 `overscroll-behavior: contain`，避免滚动穿透（`shelf-workbench.css:99-106,368-373`）；
- 不使用 `100vh` 作为唯一高度；旧内核保留 vh 回退，但必须在前一行写 vh；
- 横屏手机不能只按宽度判断，必须加 `max-height`。

## 5. 内容长度与空状态

响应式验收必须同时覆盖内容长度：

- 超长书名（80–120 字符）：卡片 2 行截断、列表单行省略、详情换行；
- 超长作者名（40+ 字符）：详情 `overflow-wrap:anywhere`，侧栏行省略；
- 无封面：`.cover-placeholder` 显示书名/作者，文字不溢出；
- 0 本：书架空状态；筛选无结果：不同文案；
- 加载：书架骨架（延迟 180ms）；详情预览骨架；
- 错误：书架错误 + 重试；详情错误 + 重试；表单错误；
- 统计空：`.chart-empty`；
- 时间/数字很长：tabular-nums，不撑破表格。

## 6. 验收宽度

至少覆盖：

`320`（最小兼容）、`360`、`390`（iPhone 竖屏）、`560`、`768`（平板竖屏）、`819/820`（断点两侧）、`932×430`（手机横屏）、`1024`、`1180/1181`（Inspector 断点两侧）、`1280`、`1440`、`1920`。

每个宽度检查：

- 无横向滚动；
- 顶栏/菜单/搜索不重叠；
- 书架封面列数符合密度；
- 弹窗不超出视口，底部操作可见；
- 触屏命中区不小于 44px；
- 安全区不遮挡内容；
- 空/加载/错误状态布局稳定。

## 7. 响应式规则

1. 不改变页面信息顺序来适配窄屏；
2. 不隐藏主操作；次要列可以隐藏（书架表格手机隐藏第 3/4/6/7 列，`shelf-workbench.css:1320-1325`）；
3. 不通过缩小字号解决溢出，优先换行、截断、堆叠；
4. 新增断点必须注明属于哪一组（全局/书架/Apple/页面局部），并加在对应源文件；
5. 不在 `max-width: 819px` 和 `min-width: 820px` 之间留空洞；
6. 横屏规则必须写在竖屏/桌面规则之后，确保层叠覆盖；
7. 不改首页画廊的 734/1068/1441 三档和 dotnav 几何；
8. 不改书架 1180 的 Inspector 浮层语义和手机横屏抽屉语义。
